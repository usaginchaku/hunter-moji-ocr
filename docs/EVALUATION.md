# 認識評価

## 公開CI回帰セット

`tests/fixtures/public-evaluation-set.ts` は、このプロジェクト用にゼロから作図した単純図形だけで構成されています。第三者の対応表、漫画、アニメ、ロゴ、スクリーンショットは含みません。

```bash
npm run test:evaluation
```

単行、逆順、反復、複数行の4画像について、分割・読順・正規化・候補順位・集計を通し、次をCIで固定します。

- 文字精度: 100%
- 全文一致率: 100%
- 抽出文字数比: 100%

この値はコード経路の回帰検出用であり、実際のハンター文字画像に対する精度ではありません。

## ローカル実画像セット

権利と公開可否を個別確認する必要がある実画像は、公開CIセットへ含めません。88枚の拾い画像は版権素材を含むためローカル評価専用とし、画像・切り抜き・派生物を公開リポジトリへ一切含めません。ブラウザ内の正解ラベル機能で、文字精度、全文一致率、抽出文字数比を記録します。

2026-08-04に現行固定版で88画像を再評価した結果は、文字精度26.09%（84/322）、全文一致4/88（4.55%）、抽出文字数比87.27%（281/322）、文字数一致32/88です。文字数一致画像だけの位置対応精度はTop-1が51/102（50.0%）、Top-3が57/102（55.88%）でした。直前参考値25.16%（81/322）からは3文字・0.93ポイントの微改善です。

文字精度の正解数は画像ごとに `max(0, 正解文字数 - 編集距離)` として集計します。編集距離が正解文字数を超える画像を負数として加算しません。

全文の編集距離だけでなく、失敗箇所を次の指標へ分解して記録します。

1. 正解と同じ文字数へ切り出せた画像の割合
2. 正しく切り出せた文字だけを母数にしたTop-1精度とTop-3精度
3. 濁点、半濁点、小書き文字ごとの検出・合成精度
4. 旧版から改善した画像、悪化した画像、変化しなかった画像の一覧

現行版では、分割不足42画像が175正解文字から108候補・24正解（13.7%）で最大のボトルネックです。文字数一致32画像は102文字中Top-1が51文字、Top-3が57文字で、単純な順位変更だけで救える範囲は限定的です。過剰分割14画像は45正解文字から71候補・9正解（20.0%）でした。

改善順は、切り出し不足、過剰分割、字形・線幅・ぼけに対する照合耐性、修飾記号と小書き判定の順とします。分割誤りを文字照合の誤りへ混ぜず、各工程の効果を別々に測ります。

画面のローカル集計は、自動認識結果とユーザー修正後の最終文字列を分離します。Top-1／Top-3と修飾別精度は、正解と抽出文字数が一致して位置対応できる画像だけを母数にします。文字数が異なる画像は文字数一致率には含めますが、位置対応した字形精度には混ぜません。

現行版から文字精度60%までは110文字、70%までは142文字、90%までは206文字の追加正解が必要です。60〜70%を個人利用向けの当面目標、90%以上を将来の理想目標とします。文字精度と全文一致率は別指標とし、片方からもう片方を推定しません。

公開回帰セットを拡充する場合は、リポジトリ内の独自SVGから一般語または独自短文を描画し、前景色・背景色・白黒反転・軽いぼけ等の自作変種を生成します。第三者作品の台詞や対応表画像は、公開評価用の入力・正解ラベルへ使用しません。

## 判定ルール

- 自動候補の得点が0.65未満
- 1位と2位の差が0.08未満
- 小書きサイズが判定境界付近
- 修飾記号の信頼度が0.55以上0.70未満

上記は文字カードを「要確認」にします。ユーザーが該当項目を明示すると、その項目の自動判定理由を解消します。
