## 指標

実グッズ90%は、事前に固定した対象文字列が全文一致した画像数 / 全評価画像数で測る。処理失敗、空出力、不正解は分母に残す。正解に応じた個別ルール、認識後の手修正、Top-3入り、画像の除外で成功を増やさない。既存開発セットと最終検証、背景条件別、元画像群別を別々に報告する。

濁点95%は、正解中の濁点付き文字のうち基底字との対応を含めた最終かなが正しい数 / 正解中の濁点付き文字数。未検出も分母に残す。文字数不一致の画像を除外する従来の位置対応Top-1／Top-3集計で代用しない。濁点の誤付与、半濁点、小書き、抽出数の不足・過剰も確認する。

生成画像での値は別集計とし、少数の濁点例や生成画像だけで一般的な95%達成とはしない。現在の既存開発セットの濁点分母は33で、1文字が約3.03ポイントに相当する。

## 次回の最小タスクと優先順

1. 保存済み失敗から抽出不足・過剰・文字数一致の誤認を各数枚選び、二値マスク・連結成分・正解文字領域をローカルで並べる。まず上表の「くろろ」「ごん」で背景混入と文字部品の統合失敗を判別する。大きな塊が「い」に似るという仮説を検証してから規則を変更する。
2. 「ふ→ぶ」の誤付与と未検出例について、本体・濁点・背景点の正解領域を付け、一対一の関連付けを検証する。33字の最終正答、濁点誤付与6字、半濁点15字、小書き14字の分母を固定して比較する。
3. 単純な3行画像で通常の「い→ぃ」が残る問題を、字形固有の占有面積と行内の相対サイズに分けて調べる。小書き判定と「要確認」の取りこぼしを自作画像で再現し、手動サイズ指定は維持する。
4. 既存88枚で改善が確認できてから、入手元と利用範囲を確認できる別の商品・背景の未使用セットを固定する。実物写真と商品紹介画像を区別し、同一商品・元画像群が開発用と最終検証へまたがらないようにする。

95%／90%を検証するための新しい画像群と字種網羅は未整備。今回の完了後に再開する場合の課題であり、今ここで追加データを待つ必要はない。
