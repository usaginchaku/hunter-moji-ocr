# ハンター文字 OCR

画像内のハンター文字を読み取り、ひらがなへ変換するブラウザアプリです。横書き・白または単純な背景・比較的鮮明な印刷文字をMVP対象としています。

長音を含む基本47字の独自SVG、濁点20通り、半濁点5通り、小書き「ぁ・ぃ・ぅ・ぇ・ぉ・っ・ゃ・ゅ・ょ」に対応し、合計81かなを出力できます。複数行の読順認識、6種類の背景処理、上位候補、信頼状態、文字単位の基底字・通常／小書き・修飾記号の修正、自動候補への復帰、最終文字列のコピーを実装済みです。

認識結果とユーザー修正は別の型付き状態として保持します。分離した濁点・半濁点も本体と記号の元画像・元IDを失わず、一対一で関連付けます。ローカル評価も修正後の文字列で自動結果を上書きせず、文字数一致、Top-1／Top-3、濁点、半濁点、小書きを別々に集計します。実画像の自動認識精度には課題が残る試験版なので、橙色の「要確認」と上位候補を確認してください。

画像の二値化後に行う文字分割とテンプレート照合はWeb Workerで実行し、長い画像の認識中も画面操作へ応答できる構成です。画像を変更した場合は実行中のWorkerを終了し、古い結果を表示しません。

## 重要事項

- 本プロジェクトは非公式ファンツールであり、作品および権利者とは関係ありません。
- 選択した画像はブラウザ内だけで扱い、アプリから外部サーバーへ送信しません。
- 第三者が公開するハンター文字対応表画像、とくに転載禁止と記載された画像は、公開リポジトリへ転載しません。
- 公開用の字形テンプレートは、独自に作図したSVGまたは利用権限を確認できる素材だけを使用します。
- OpenCV.js 4.13.0の公式配布物をリポジトリ内へ同梱しています。起動時の外部通信はなく、選択画像や認識文字列も送信しません。
- ファイル上限は20 MB、入力画像は最大100,000,000画素・最大辺32,768px、認識処理は縦横比を保って最大辺2,048pxへ縮小します。

## 必要環境

- Node.js 24以上
- npm 11以上

## ローカル実行

```bash
npm install
npm run dev
```

開発サーバーが表示したURLをブラウザで開きます。

## ハンター文字画像メーカー

OCR画面の「文字画像を作る」から、または開発サーバーの
`/generator.html` を直接開いて利用できます。

- ひらがな、濁点・半濁点、小書き「ぁ・ぃ・ぅ・ぇ・ぉ・っ・ゃ・ゅ・ょ」、長音、空白、改行に対応
- 文字色、背景色、透明背景、文字サイズ、文字間隔、余白、1行の文字数を調整可能
- 入力に合わせてブラウザ内でプレビューを更新し、PNGとして保存
- 未対応文字は枠付きで表示し、状態欄でも通知

入力文字列と生成画像は外部サーバーへ送信しません。字形には公開用に独自作図したSVGだけを使用しています。

## GitHub Pagesへの公開

1. GitHubで `hunter-moji-ocr` リポジトリを作成します。
2. このプロジェクトを `main` ブランチへpushします。
3. リポジトリの **Settings → Pages → Source** で **GitHub Actions** を選択します。
4. `Deploy to GitHub Pages` ワークフローの完了を確認します。
5. Pagesのカスタムドメインに `hunter-ocr.mochibird.click` を設定し、
   `https://hunter-ocr.mochibird.click/` を開きます。

Viteの公開パスは、カスタムドメイン直下で配信するため `/` に設定しています。
DNSでは `hunter-ocr.mochibird.click` のCNAMEを `usaginchaku.github.io` に向け、
GitHub Pages側にも同じカスタムドメインを設定します。

GitHub Pagesへ公開したページは、URLを知っている人なら誰でも閲覧できます。HTMLの
`noindex,nofollow,noarchive` は検索エンジン向けの依頼であり、アクセス制御や非公開化を
行うものではありません。

## 現在の制約

- ドラッグした範囲だけを認識できます。背景付き画像も実験対応していますが、人物の輪郭や髪が文字に接する画像では、文字以外を拾ったり複数文字をまとめたりすることがあります。
- 複数文字の濁点・半濁点と小書き文字は自動判定します。誤判定時は文字候補・修飾記号・正解ラベルを手動で修正できます。
- 1文字照合は単純な背景上の鮮明な文字を対象とする実験版です。暗い背景上の明るい文字は、輝度分布と外周から判定できる場合に自動反転します。
- 対応画像形式はPNG、JPEG、WebP、ファイル上限は20 MBです。
- 手書き、縦書き、極端な遠近変形、低解像度、漫画の複雑背景からの完全自動抽出はMVP対象外です。
- 現在の画像処理はCanvasとTypedArrayを使用し、OpenCV.jsの`Mat`は生成していません。将来`Mat`を導入する場合は、生成元を含めて`finally`で明示的に`delete()`します。

OpenCV.jsはOpenCV 4.13.0公式リリースの配布物です。ライセンス全文は `public/vendor/opencv/LICENSE.txt` に同梱しています。

## 現在の字形テンプレート

- 横書きの基本47文字（長音を含む）の独自SVGドラフト
- 64×64キャンバス
- Canvas経由の64×64二値化
- 前景率・縦横比・X/Y射影の生成
- ビットマップ・射影・縦横比・前景率を組み合わせた候補ランキング
- 上下左右2pxの位置ずれを使った414文字分の自動精度評価
- 濁点20通り・半濁点5通りのかな合成と未対応判定
- 「ぁ・ぃ・ぅ・ぇ・ぉ・っ・ゃ・ゅ・ょ」のかな合成と、基本字形を70%へ縮小する二値画像処理
- 横書き候補の行グループ化、左から右・上から下の読順整列、行内の相対サイズ算出
- 連結成分ノイズ除去、近接する線・点の統合、複数行の文字候補抽出
- 背景色推定、暗い線、局所コントラスト、局所色差、Sauvola、無彩色の黒線の6方式による二値化と、照合品質による自動選択
- 背景ノイズでつながった横長候補を投影の谷から再分割
- 分離した濁点・半濁点の再結合と、孤立点・枠線による過分割を抑える形状品質評価
- プレビューをボタン・スライダー・マウスホイールで100〜400%に拡大し、右ドラッグで移動しながら左ドラッグで行える、非破壊の認識範囲選択と全体へのリセット
- 複数文字の上位3候補表示と、全47文字から選べる文字単位の修正
- 複数文字への濁点・半濁点の手動合成と未対応組み合わせの抑止
- 認識結果・候補修正からの正解ラベル仮入力、手動編集、画像ごとのブラウザ内保存、個別評価とローカル累計評価
- 対応表画像の切り抜き・埋め込みなし
- 作図ルール: `docs/GLYPH_DRAWING_RULES.md`

実装状況と未検証項目は [`docs/MVP_STATUS.md`](docs/MVP_STATUS.md)、評価セットの区別は [`docs/EVALUATION.md`](docs/EVALUATION.md) を参照してください。

## 黒背景・低コントラスト画像

輝度分布と画像外周を調べ、明るい文字と確信できる場合だけ白黒を反転して既存の6方式へ渡します。低コントラストの単純な無彩色画像には条件付きでコントラスト補正を行います。白背景・黒文字など、反転や低コントラスト補正が不要な画像はそのまま処理します。補正内容は認識方式名とブラウザのデバッグログで確認できます。

[前処理の比較評価](docs/PREPROCESSING_EVALUATION.md)に、条件・変更前後の結果・残る制約を記録しています。[実グッズ画像と濁点の再開用記録](docs/REAL_IMAGE_EVALUATION.md)には測定値・失敗例・試した方法・次回の課題・ローカル再実行手順を保存しています。
