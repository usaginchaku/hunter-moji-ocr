# MVP実装状況

## 実装済み

- 横書き、白または単純な背景、濃色の印刷文字
- ブラウザ内の画像読込、EXIF方向反映、非破壊切り抜き
- 6種類の二値化、ノイズ除去、行・文字候補の抽出
- 長音を含む基本47字の独自SVGとテンプレート照合
- 濁点20通り、半濁点5通り、小書き9字の合成（小書き母音の自動判定は次工程）
- 本体と修飾成分を別画像・別IDで保持する一対一関連付け
- 自動判定とユーザー修正を分離した型付き状態
- 基底字、通常／小書き、なし／濁点／半濁点の文字単位修正
- 要確認理由、上位候補、自動候補への復帰、結果コピー
- ブラウザ内だけの正解ラベル保存と評価集計
- 第三者素材を含まない公開CI回帰セット
- GitHub Pagesの `/hunter-moji-ocr/` 配下へのビルドと自動配信
- ImageBitmapの明示的解放、Object URL破棄、処理解像度と入力画素数の上限
- 文字分割・照合のWeb Worker実行、画像変更時の中止とWorker解放

## 公開前に再確認する項目

- 最新コードでローカル88画像を再評価し、60〜70%の実用目標と90%の理想目標までの差を確認する
- GitHub Pagesの実URLで画像読込、SVG、OpenCV.js、コピーを確認する

## 2026-08-04の実ブラウザ確認

- 390×844pxで横スクロールが発生せず、画像選択、認識、文字単位の修正、コピー結果が1列表示に収まることを確認
- カスタムドメイン直下と同じ`/`基準のローカル配信でHTML、ビルド済みJS/CSS、字形SVG、OpenCV.jsがHTTP 200になることを確認
- 長い実画像は、分割境界探索の上限導入前が約65秒、導入後が約46秒で、どちらも11文字候補を抽出。Worker移行後も総時間は約46秒だが、処理中の状態確認397回すべてに応答し、応答失敗は0回
- 代表画像では、`ぽんず_01`が3候補（末尾の濁点を自動合成）、`ぽっくる_01`が4候補（先頭の半濁点と2字目の小書きを自動合成）。認識文字列の誤りは残るため、88画像再評価と精度改善を継続する

## MVP対象外

- 縦書きの完全対応
- 手書き文字
- 漫画の複雑背景からの完全自動抽出
- 極端な遠近変形や低解像度
- 機械学習、外部サーバー、学習データ収集

対象外の機能を追加する場合も、画像を外部へ送らない原則と、公開素材の権利確認を維持します。
