# 独自SVG字形の作図ルール

## 目的

公開リポジトリで利用できるハンター文字テンプレートを、参照画像の切り抜きやトレース画像を使わず、基本図形から独自に作図する。

## 基本仕様

- キャンバスは `64 × 64`、`viewBox="0 0 64 64"` とする。
- 通常字形の外側余白は、おおむね12〜16ピクセル確保する。
- 線は黒色、基本線幅は `5.5` とする。
- 線端と線の接続は原則として丸める。
- 円形の塗りつぶしが字形要素である場合だけ `fill="#111"` を使う。
- `<image>`、外部フォント、外部URL、埋め込みラスター画像は使用しない。
- 横書きと縦書きで字形が異なる場合は、別SVGとして管理する。

## 作図手順

1. 参照表を人間が目視し、線分・円・多角形の組み合わせとして構造を整理する。
2. 64×64キャンバス上で、左右・上下の余白が偏らないように独自作図する。
3. SVG単体を一覧表示し、線幅と視覚上の大きさを比較する。
4. 正規化後の64×64ビットマップでも形状が潰れないことを確認する。
5. 自作テスト画像で認識評価を行ってから `ready` とする。

## 禁止事項

- 対応表画像そのもの、または対応表から切り抜いた画像を含めない。
- 参照画像をbase64等でSVGへ埋め込まない。
- 「転載禁止」と記載された画像をテストデータとして公開しない。
- 推測だけで字形とかなの対応を追加しない。

## 現在の対象

現在の確認対象は、清音・「を」・「ん」を含む基本46文字とする。すべて評価中のドラフト字形として扱う。
