# 実グッズ画像と濁点精度の評価条件

2026-09-12に引き継いだ目標:

- 黒背景・白文字の読み取り
- 濁点付き文字の最終出力精度95%以上
- 生成画像を除く既存グッズ画像の全文一致率90%以上。背景がきれいでない画像を含む
- 通常の白背景・黒文字の認識性能を維持

`manifest.csv` は元ファイル、元タイル番号、タイル内の切り抜き座標と正解ラベルを持つ。上位の `character-name-tiles/manifest.csv` は元画像からタイルを切り出した座標を持つ。今回の入力は既存の切り抜きPNG全体とし、認識結果を見て切り抜きを変更しない。モードは `auto`、手修正なし。内容ハッシュ・寸法・正解・設定を別のローカル監査JSONへ記録した。

元画像はAMNIBUSのグッズ紹介カタログと見られる画像で、文字と人物絵が重なっている。少なくとも確認したJPEG群は実物を撮影した写真ではなく商品紹介用の画像。入手元URLの厳密な対応付けは未確認。全体322文字はアプリの合成画像ではないが、実物写真・他の商品・未知の背景への一般化の証拠にはしない。

7ファイルからの切り抜き数は14、14、10、13、12、12、13枚。似た商品・絵柄を含むため、88枚を独立した88商品とは扱わない。ファイルが完全一致しないことは、近似画像や同一商品の重複がないことを意味しない。

この88枚は過去の開発で使用済みであり、全体を既存開発セットとして扱う。後からランダムに分割して「未使用の最終検証」とは呼ばない。最終検証用には開発で使用していない商品群が必要で、追加画像の所在をユーザーへ照会中。

## 指標

実グッズ90%は、事前に固定した対象文字列が全文一致した画像数 / 全評価画像数で測る。処理失敗、空出力、不正解は分母に残す。正解に応じた個別ルール、認識後の手修正、Top-3入り、画像の除外で成功を増やさない。既存開発セットと最終検証、背景条件別、元画像群別を別々に報告する。

濁点95%は、正解中の濁点付き文字のうち基底字との対応を含めた最終かなが正しい数 / 正解中の濁点付き文字数。未検出も分母に残す。文字数不一致の画像を除外する従来の位置対応Top-1／Top-3集計で代用しない。濁点の誤付与、半濁点、小書き、抽出数の不足・過剰も確認する。

生成画像での値は別集計とし、少数の濁点例や生成画像だけで一般的な95%達成とはしない。現在の既存開発セットの濁点分母は33で、1文字が約3.03ポイントに相当する。
